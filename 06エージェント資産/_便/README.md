# _便 — 時計が決まった時刻に起こす席

**この箱は空で渡される。**

| 何 | 中身 |
|---|---|
| 何がここに入るか | 時計（scheduler）が**決まった時刻に起こす席へのエイリアス**。名前の頭が時刻（`{HHMM}-{便}.md`）＝開いた瞬間に「何時に何が回るか」が目で見える |
| 誰が張るか | 孔明。席を建てたその場で「**この席を、毎朝決まった時刻に回しますか**」と聞き、**はい**ならここに 1 本張る |
| 実体はどこか | `06エージェント資産/` の直下（本文）。**⛔ ここに実体を置かない**——正本を 2 つにしない |
| `_孔明起動/` との違い | あちらは孔明が起きたときに一緒に起きる席。**⛔ 同じ席を両方に置かない**（二重起動。生成器の `--check` が数える） |
| 誰が読むか | **人が目で見るための箱。**回すのは時計であって、孔明の手番は無い ⇒ 孔明は起動時にここを見ない |

張り方: 台帳 `_台帳-便.csv` に 1 行足して `python3 scripts/build_agent_aliases.py` を撃つ。
