# AgentOS 器キット

AI エージェント（丞相「孔明」）が働ける棚「AgentOS」の**器**です。建てた棚の名前は既定で AgentOS（席が聞いて変えられます）。規則の紙 3 枚・空の箱・道具・門・雛形だけが入っています。講座・カード・帳簿・裁定などの中身は入っていません。

- 使い方: 初期セットアップの席（エージェント）がこのリポを一時領域に clone し、あなたの棚をあなたの機体に建てます。**人が手で clone して展開する必要はありません。**
- 更新: 毎朝、生きている棚から `scripts/make-kit.sh` で切り出し直して push されます（固有値 0 件の門つき）。
- 中身の説明は `CLAUDE.md` と `.claude/rules/` の 3 枚に在ります。
