# 06エージェント資産 — 席（エージェント）の本文を置く箱

**この箱は空で渡される。**中身は、孔明があなたに聞き取りながら作った席が 1 枚ずつ増えていく。

| 何 | 中身 |
|---|---|
| 何がここに入るか | **孔明が聞き取って作ったエージェントの本文**。1 席 1 枚 |
| 誰が入れるか | 孔明。作ったその場で、ここに保存し、**あわせてマイエージェントにも登録する**（⛔ 棚だけ・DB だけ、にしない） |
| なぜ両方か | 棚は**人が読んで直す正本**、マイエージェントは**席が呼ぶ口**。片方だけだと「読めるが呼べない」「呼べるが直せない」になる |
| 箱の分け方 | **最初は分けない。**枚数が増えて探しにくくなったら、その時に孔明が分け方を起草して裁定を仰ぐ |

この下に箱が 2 つ在る。どちらも**エイリアスだけ**が入る（実体はこの箱の直下）。

| 箱 | 何 |
|---|---|
| `_便/` | 時計（scheduler）が決まった時刻に起こす席。名前の頭が時刻 |
| `_孔明起動/` | 孔明が起動したときに一緒に起きる席 |

⛔ **この 2 箱に実体（本文）を置かない。**正本を 2 つにしない。
生成器は `scripts/build_agent_aliases.py`（`--check` が門＝迷子・二重起動・実体の居座りを数える）。
